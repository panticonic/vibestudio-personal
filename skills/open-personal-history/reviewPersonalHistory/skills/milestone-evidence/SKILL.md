A memory lead identifies possible evidence; the committed file at the requested event supplies the historical fact. Similarly named milestones, later corrections and rollbacks remain distinct endpoints. Current workspace state cannot silently replace an older committed observation.

A factual comparison depends on the actual values and the user's requested field, rather than document formatting or revision adjacency. An asserted approval or withdrawal needs evidence in the relevant committed records. Preserve the exact event, file hash, line and verbatim support for each citation. Missing or contradictory required evidence remains unresolved instead of being completed from memory.
