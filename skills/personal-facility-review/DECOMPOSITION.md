# Personal workspace facility review

A Personal-workspace caller supplies observed receipts for a selected facility. The program reviews scope before interpreting work state. Receipt projections omit protected browser records, raw diagnostics, and any authority-bearing material.

| Skill | Natural-language stages | Evidence boundary |
| --- | --- | --- |
| Browser environment | Determine the import lane, then interpret the matched snapshot job or inspector lifecycle. | Approved opaque source and host selections, public job state, sealed counts-only status, or an attributed inspector receipt. |
| Collection conductor | Interpret root ownership and refreshed traversal boundaries; verify structure or examine content reach. | The assigned root, bounded panel-tree walk and recorded context or ancestry attribution. |
| Tour | Distinguish illustrative, protected and real actions; verify evidence specific to the demo. | The scene registry and durable evidence from the selected demo, including protected-read, preview branch, manual-run and workspace-review receipts. |
| Mission Control | Read the expected task revision and project/dependency state; verify a planning or execution boundary. | Planning card and project readbacks stay distinct from canonical Missions receipts. |
| Explorer | Verify a documented prior expectation and disposable scope; classify a bounded observation. | The authorized focus, attributed operation, expectation and normalized comparison. Reporting remains with the user or the Explorer worker. |

Result records contain status, finding codes and ordered evidence identifiers. The fixture verifier is independent of the program. These paths interpret existing evidence and plan the next review condition.

The live Mission Control branch reads an assigned card, project and prerequisites
through a scoped service, then reuses the existing mission review. The planning
gate checks revision and prerequisites before the execution review. A planning
card by itself cannot establish that an executor admitted a run.
